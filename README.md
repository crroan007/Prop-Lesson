# DA42 Propeller System — Interactive Lesson

An interactive, single-page HTML lesson covering the Diamond DA42 NG/VI Propeller System. Built as a lightweight LMS designed for learners who benefit from multiple modalities and frequent knowledge checks.

## Features

- **Cockpit HUD Aesthetic** — Amber/green avionics-inspired dark theme with military typography
- **7 Interactive Quizzes** — Inline knowledge checks with instant feedback and confetti celebrations
- **Multiple Modalities** — Visual diagrams, analogies, checklists, and audio narration
- **Shatner TTS Integration** — Optional voice narration via local Chatterbox TTS server (falls back to browser speech)
- **Keyboard Navigation** — Arrow keys to navigate sections, `S` to trigger narration
- **Progress Tracking** — HUD-style progress bar and score tracker
- **Memory Items Checklist** — Interactive checklist for engine failure procedures

## Topics Covered

1. Fixed vs Variable Pitch Propellers
2. FADEC & Propeller Set Point Curve
3. MT Propeller Construction & Preflight
4. Propeller Control System (Governor, Oil Pressure, Counterweights)
5. Pressure Accumulator & Feathering Sequence
6. Emergency Procedures (Oscillating RPM, Overspeed, Fixed RPM)
7. Engine Failure Memory Items & Restart Procedures

## Usage

Open `index.html` in any modern browser. No build step or server required.
